# BuildMatch — مبادئ التصميم ومواصفات نظام التصميم (Design Tokens & Principles)

## 1. المبادئ التصميمية الأساسية (Design Principles)
1. **الوضوح والشفافية الهندسية:** عرض بنود الأسعار والمقايسات وجداول الدفعات بأرقام ونسب واضحة دون أي مصطلحات مبهمة، مع إبراز ما هو مشمول وما هو مستبعد من العرض.
2. **الكفاءة وسرعة الوصول:** تقليل عدد النقرات اللازمة للوصول للفرص المفتوحة أو تقديم العروض أو اعتماد المراحل، مع الاعتماد على بطاقات معلومات منظمة وجداول مقارنة بديهية.
3. **الأصالة المحلية (Egyptian Context):** تصميم يراعي المصطلحات الهندسية وسياق السوق السكني في مصر (عظم، سباكة، تشطيب، دفعة مقدمة، استلام، روف، بدروم).
4. **التدرج البصري والتركيز على الإجراء (Call to Action):** إبراز القرارات المصيرية مثل الترسية أو اعتماد طلب التعديل أو التوثيق بألوان واضحة وتأكيدات صريحة.

## 2. مواصفات نظام الرموز (Design Tokens Specification)

### لوحة الألوان المعتمدة (Color Palette)
- **الأزرق الهندسي (Brand Primary):**
  - `brand-50`: `#f0f7ff` (خلفيات ناعمة وبادجات)
  - `brand-500`: `#0c87eb` (حالة التركيز والتفاعلات)
  - `brand-600`: `#026bc9` (اللون الأساسي للأزرار والروابط)
  - `brand-700`: `#0355a2` (العناوين والبراند الرئيسي)
  - `brand-900`: `#0c3d6e` (النصوص الداكنة والرؤوس)
- **ألوان البناء الإنشائية (Construction Accents):**
  - أصفر ورش البناء والتحذير: `#f59e0b` (`construction-amber`)
  - رمادي الخرسانة والأحجار: `#78716c` (`construction-stone`)
  - كحلي الحديد والصلب: `#334155` (`construction-slate`)
- **ألوان الحالات الوظيفية (Semantic Colors):**
  - النجاح والاعتماد: `#10b981` (Green-600)
  - التنبيه والمراجعة: `#f59e0b` (Amber-500)
  - الخطر والرفض: `#ef4444` (Red-500)

### الخطوط والطباعة (Typography)
- **عائلة الخط الأساسية:** `Inter, system-ui, -apple-system, sans-serif` مع دعم كامل للخط العربي الحديث `Cairo / Tahoma`.
- **أحجام النصوص:**
  - `H1 (Page Title):` 32px / Bold / Leading 1.2
  - `H2 (Section Title):` 24px / SemiBold / Leading 1.3
  - `H3 (Card Title):` 18px / SemiBold / Leading 1.4
  - `Body Text:` 14px / Regular / Leading 1.5
  - `Small / Metadata:` 12px / Medium / Leading 1.4

### المسافات والزوايا (Spacing & Radii)
- حواف المكونات والبطاقات: `rounded-xl` (12px) أو `rounded-lg` (8px).
- تباعد العناصر الداخلي (Card Padding): `p-6` (24px).
- تباعد الأزرار والحقول: `px-4 py-2` للأحجام المتوسطة.
