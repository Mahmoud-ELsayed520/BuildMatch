# BuildMatch — بيان نطاق المشروع (Scope Statement)

## 1. النطاق المعتمد للنسخة الأولية (In-Scope — MVP)
يتضمن نطاق الإصدار التجريبي الأولي (MVP) النطاقات التالية:
1. **نظام المصادقة وإدارة الحسابات:**
   - تسجيل الملاك والمقاولين واختيار الدور.
   - منع التسجيل المباشر كمدير نظام (Admin Escalation Prevention).
   - إدارة الجلسات وحماية المسارات.
2. **ملف المقاول والتوثيق الإداري:**
   - رفع مستندات السجل التجاري والبطاقة الضريبية وهوية المهندس.
   - مراجعة واعتماد أو رفض التوثيق من قبل إدارة المنصة.
   - حصر تقديم العروض على المقاولين الموثقين فقط.
3. **نشر وإدارة مشاريع الملاك:**
   - تحديد بيانات الموقع (المدينة، الحي)، المساحة، الأدوار، الميزانية ونوع البناء.
   - رفع الرسومات الهندسية المعتمدة والتراخيص.
   - تجزئة المشروع إلى حزم عمل مستقلة (Work Packages).
4. **تصفح واكتشاف حزم العمل للمقاولين:**
   - محرك بحث وتصفية للمشاريع المنشورة حسب المدينة والمجال.
   - فحص متطلبات الحزم الهندسية والمخططات.
5. **تقديم ومقارنة العروض:**
   - تقديم عروض منظمة تشمل السعر الإجمالي، المدة، ملخص النطاق، والمواد المشمولة والمستبعدة.
   - مصفوفة مقارنة معيارية بين العروض المتقدمة لكل حزمة.
6. **ترسية حزم العمل الذرية (Atomic Selection):**
   - اختيار مقاول فائز واحد للحزمة الواحدة عبر دالة قاعدة بيانات ذرية (RPC).
   - تحويل الحزمة إلى حالة مسندة (Assigned) ورفض بقية العروض آلياً.
7. **إدارة مراحل التنفيذ الميداني:**
   - متابعة مراحل العمل (Milestones)، رفع التحديثات ونسب الإنجاز المصورة.
   - إدارة واعتماد أو رفض طلبات التعديل (Change Requests).
   - طلب واعتماد الاستلام والتسليم النهائي للحزمة.
8. **لوحة الإدارة والتقييمات:**
   - لوحة إشرافية لمراجعة طلبات التوثيق وسجلات التدقيق (Audit Logs).
   - تسجيل تقييمات موثقة بعد اكتمال الحزمة فقط.

## 2. النطاق المستبعد من النسخة الحالية (Out-of-Scope)
- بوابات الدفع الإلكتروني المباشر وحسابات الضمان المالي (Escrow Services).
- المحادثات المباشرة الفورية (Real-time Live Chat).
- التقدير الآلي لتكاليف البناء عبر الذكاء الاصطناعي (AI Cost Estimation).
- سوق توريد خامات ومواد البناء (Building Materials Marketplace).
- سوق الخدمات الاستشارية والتصميم المعماري.
- تطبيقات الهواتف الذكية الأصلية (Native iOS / Android).
- التوقيع الإلكتروني القانوني للعقود.
